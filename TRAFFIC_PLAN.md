# Moonwhisper — Traffic Plan (US / English, zero-budget)

Niche: Angel Numbers + Dream Dictionary (US audience). Goal metric: **25,000 monthly pageviews with 50%+ US/UK/CA/AU traffic → Raptive ($15–50 RPM)**. AdSense is the warm-up.

## Channel priority (best fit for this niche)
1. **Pinterest ⭐ (highest ROI here)** — angel numbers & dream meanings are among the biggest evergreen Pinterest categories. Visual, evergreen, compounding referral. No follower base needed.
2. **YouTube Shorts** — reuse our video pipeline + ElevenLabs (English voice). "111 angel number meaning", "dream about snakes".
3. **TikTok** — same shorts repurposed ("angel numbers"/"dreamtok" are huge). 
4. **Instagram Reels + carousels** — same verticals + infographic carousels.
5. **Google organic (SEO/GEO)** — long-tail, already FAQ/JSON-LD optimized; slow but compounding. (sitemap submitted)
6. **Reddit/Quora (value-first)** — answer in r/dreams, r/Psychic, r/spirituality with genuine help + soft link. No spam.

## The repeatable unit (per blog post)
Each of the 60 posts → **1 Pinterest pin + 1 vertical short (YT/TikTok/Reels)** → link back to the post.
- Pin image: bold title on starry-night brand bg (our SVG/nano_banana engine).
- Short: hook ("Keep seeing 111?") → answer → "full meaning in bio/description" → URL.

## Zero-cost engine reuse
- **Video**: existing `build_iconvideo.cjs` / `build_cardvideo.cjs` + `eleven_tts` (switch to a native English voice id).
- **Pin graphics**: SVG→PNG (headless Chrome) or nano_banana batch.
- **Publishing**: manual at first; YouTube uploader pattern reusable.

## Cadence (weekly, sustainable)
- **Pinterest**: 3–5 pins/day (mix new + re-pin to boards "Angel Numbers", "Dream Meanings"). This is the workhorse.
- **Shorts (YT+TikTok+Reels)**: 1/day, cross-posted to all three.
- **Content**: keep expanding angel numbers (programmatic 100–999 + sequences) & dream A–Z.

## Phased targets
- **Weeks 0–4**: Google indexes 60 pages; Pinterest pins start ranking; first clicks. Set up boards, publish first 20 pins + 7 shorts.
- **Weeks 4–12**: Pinterest + Shorts compound → first few thousand PV/mo. Apply AdSense (existing KR account, add site) once real traffic shows.
- **Month 3–6**: push toward 25k PV/mo → **Raptive**. Then buy a brandable `.com` and migrate.

## First-week action checklist
1. Create Pinterest business account + boards (Angel Numbers, Dream Meanings, Zodiac).
2. Generate 20 pin images (top posts) → schedule.
3. Produce 5 English shorts from top posts (111, 1111, dream-about-snakes, teeth, being-chased).
4. Cross-post shorts to YouTube + TikTok + Reels with URL in description.
5. Request Google indexing for the 10 highest-intent URLs (Search Console → URL inspection).
